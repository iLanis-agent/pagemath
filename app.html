Page Math

Boundary: arithmetic only This page does whole-number pagination arithmetic on the numbers you type. It does not know how any real database, API or website pages its results, and it gives no verdict on whether your paging is right or fast. Every figure is your own entry.

The page truth

How many pages, what the last one holds, and what one page shows.

The locate truth

Which page an item lands on, counting items from 1.

The window truth

Which page links a pager of a set width shows.
